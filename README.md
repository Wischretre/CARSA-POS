# CarSaPOS - Carl Andrey C. Sabares

## Setup
1. Extract `Database & App.zip`.
2. In SSMS, run `01_CreateDatabase.sql`.
3. Run `CarSaPOS.exe` from the extracted folder.
4. Sign in with the admin account: username=`admin`, password=`carlgwapo`.

## Logs
Error logs are written to `%ProgramData%\CarSaPOS\Logs`.
